DESKTOP ATTENDANCE SOFTWARE

Simple attendance management for educators.

Attendance Manager is a desktop application for organizing students, classes, QR-based attendance, and attendance records. Optional Google integration provides supported Google productivity features.

Learn more Privacy Policy

Application features

Student management

Manage student, course, year, section, class, and enrollment information.

QR attendance

Record attendance using QR-based identification and manage attendance records locally.

Google integration

Optionally connect a Google account for supported Google Drive, Sheets, and Forms functionality.

Offline-first

The core application operates locally, with Google integration available as an optional feature.

Google account access

Google account access is optional. When a user chooses to connect a Google account, Attendance Manager uses Google's OAuth authorization flow.

The user reviews the requested permissions on Google's consent screen and decides whether to grant access.

The application requests only the permissions required for supported features.

Data protection

Attendance Manager is designed to keep core attendance and student information on the user's computer.

Google data is accessed only when the user enables a supported Google integration feature.
